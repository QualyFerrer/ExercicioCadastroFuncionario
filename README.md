# 📌 Sistema de Gestão de Funcionários (CLT e PJ)

Este projeto é um **sistema simples em Java, executado via console**, para gerenciar funcionários de uma empresa, permitindo o cadastro de funcionários **CLT** e **PJ**, listagem, busca por nome e cálculo da folha de pagamento.

---

## 🚀 Funcionalidades

- ✅ Adicionar funcionário **CLT**
- ✅ Adicionar funcionário **PJ**
- 📋 Listar todos os funcionários cadastrados
- 🔍 Buscar funcionário pelo nome
- 💰 Calcular a **folha de pagamento total**
- ❌ Encerrar o sistema

---

## 🧠 Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Herança
- Polimorfismo
- Encapsulamento
- Classes abstratas (ou base)
- Uso de `Scanner` para entrada de dados
- Organização em pacotes (`application` e `entities`)
